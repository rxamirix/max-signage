# سایت تابلوسازی مکس (MAX)

سایت شرکتی معرفی خدمات و نمونه کارهای تابلوسازی مکس در استان مازندران، با تمرکز بر سئوی محلی و افزایش تماس مشتریان.

- شعار برند: **مکس برای دیدن** (MAX FOR SEE)
- شعب: بهشهر (میدان قدس) و نکا (مقابل اداره دارایی)
- تماس: ۰۹۱۱۲۵۸۸۸۴۶

## استک فنی

| مورد | انتخاب |
| --- | --- |
| فریم‌ورک | Next.js 16 با App Router |
| زبان | TypeScript |
| استایل | Tailwind CSS v4 |
| فونت | KookFaNum (محلی، woff2) |
| رندر | تولید استاتیک (SSG) برای همه صفحات |

## اجرای پروژه

```bash
npm install
npm run dev      # اجرا روی http://localhost:3000
npm run build    # ساخت نسخه نهایی
npm run start    # اجرای نسخه ساخته‌شده
```

## ساختار پروژه

```
app/

  [locationSlug]/             ۶ صفحه شهری سئو (ساری، بهشهر، نکا، قائم‌شهر، آمل، بابل)
```

## ویرایش محتوا

تمام متن‌های سایت در پوشه `lib` متمرکز شده‌اند و برای تغییر آن‌ها نیازی به دست زدن به کد صفحات نیست.

| می‌خواهید چه چیزی را عوض کنید | کدام فایل |
| --- | --- |
| شماره تماس، آدرس شعب، آمار، منو | `lib/site.ts` |
| متن و مشخصات خدمات | `lib/services.ts` |
| نمونه کارها و تصاویرشان | `lib/projects.ts` |
| محتوای صفحات شهری | `lib/locations.ts` |
| مقالات | `lib/posts.ts` |
| متریال، مراحل کار، نظرات مشتریان، سوالات متداول | `lib/content.ts` |

### افزودن شهر جدید

یک آیتم به آرایه `locations` در `lib/locations.ts` اضافه کنید. صفحه، لینک‌های داخلی، sitemap و داده ساختاریافته به‌صورت خودکار ساخته می‌شوند.

### افزودن نمونه کار جدید

یک آیتم به آرایه `projects` در `lib/projects.ts` اضافه کنید و تصاویر آن را در `public/images/portfolio/` بگذارید. راهنمای تصاویر در `public/images/portfolio/CONTENT.md` آمده است.

## فرم استعلام قیمت

فرم به‌جای ارسال به سرور، اطلاعات را در قالب یک پیام آماده در واتساپ باز می‌کند. مزیت این روش این است که سایت کاملاً استاتیک می‌ماند، به بک‌اند و پایگاه داده نیاز ندارد و پیام مستقیماً روی موبایل شما می‌آید. شماره واتساپ در `lib/site.ts` قابل تغییر است.

## انتشار

سایت استاتیک است و روی هر هاستی قابل انتشار است.

1. مقدار `url` در `lib/site.ts` را به دامنه نهایی تغییر دهید (پیش‌فرض: `https://maxtablo.ir`).
2. `npm run build` را اجرا کنید.
3. برای سرویس‌هایی مثل Vercel یا لیارا، مخزن را متصل کنید تا خودشان build را اجرا کنند.

پس از انتشار، مراحل `SEO-CHECKLIST.md` را دنبال کنید. مهم‌ترین آن‌ها ثبت در Google Search Console و ساخت پروفایل Google Business برای هر دو شعبه است.
